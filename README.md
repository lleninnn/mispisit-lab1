# FraudGuard — система фрод-мониторинга транзакций

FraudGuard — учебная информационная система для регистрации и экспертной проверки финансовых транзакций. Приложение позволяет добавлять подозрительные операции, просматривать реестр транзакций, выносить решения «Ок» или «Фрод» и анализировать данные через Grafana.

Текущая версия: **0.0.4**.

## Реализованный функционал

- реестр зарегистрированных финансовых транзакций;
- добавление новой транзакции через форму;
- экспертная проверка транзакции со статусом «На проверке»;
- вынесение вердикта «Ок» или «Фрод»;
- запрет повторного изменения завершённой транзакции;
- отдельная страница ошибочного сценария `/access-denied/`;
- постоянное хранение данных в PostgreSQL;
- аналитическая панель Grafana на основе данных PostgreSQL.

## Архитектура

| Сервис | Назначение | Порт наружу |
|---|---|---:|
| `app` | Веб-приложение FraudGuard | `8080` |
| `db` | Сервер PostgreSQL | не публикуется |
| `dashboard` | Grafana с готовым dashboard | `3000` |

Приложение подключается к PostgreSQL по внутреннему имени сервиса `db`.

Данные PostgreSQL сохраняются в именованном Docker-томе `dbdata`, поэтому они не удаляются при пересоздании контейнера базы.

## Требования

Для запуска проекта необходимы:

- Docker Engine;
- Docker Compose plugin;
- свободные порты `8080` и `3000`.

## Запуск проекта

Репозиторий: https://gitverse.ru/lleninnn/mispisit-lab1  
Ветка: `lab4`  
Pull Request: https://gitverse.ru/lleninnn/mispisit-lab1/pulls/6  
Образ приложения: `lleninnn/mispisit-lab1:0.0.4`  
Страница образа: https://hub.docker.com/r/lleninnn/mispisit-lab1  

Выполните команды:

```bash
git clone -b lab4 https://gitverse.ru/lleninnn/mispisit-lab1
cd mispisit-lab1
docker compose up -d
```

При первом запуске Docker скачает образ приложения, PostgreSQL и Grafana. Структура таблицы транзакций создаётся автоматически при старте приложения.

## Адреса после запуска

Веб-приложение:

```text
http://localhost:8080
```

Grafana:

```text
http://localhost:3000
```

Учебные параметры Grafana:

```text
Логин: app
Пароль: app
```

## Основные страницы приложения

- `/` — аналитическая панель приложения;
- `/transactions/` — реестр транзакций;
- `/transactions/new/` — регистрация новой транзакции;
- `/transactions/&lt;id&gt;/` — карточка проверки транзакции;
- `/access-denied/` — страница отказа.

## Проверка сохранения данных

После запуска:

1. Откройте `http://localhost:8080/transactions/`.
2. Добавьте новую транзакцию.
3. Убедитесь, что она появилась в списке.
4. Выполните:

```bash
docker compose down
docker compose up -d
```

5. Снова откройте список транзакций.

Добавленная запись должна остаться на месте.

## Остановка проекта

Остановить и удалить контейнеры, сохранив данные:

```bash
docker compose down
```

Остановить проект и полностью удалить данные PostgreSQL:

```bash
docker compose down -v
```

Внимание: команда с флагом `-v` удаляет данные базы.

## Конфигурация окружения

Значения задаются в `docker-compose.yml`:

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | Секретный ключ Django |
| `DB_NAME` | Имя базы данных |
| `DB_USER` | Пользователь базы данных |
| `DB_PASSWORD` | Пароль базы данных |
| `DB_HOST` | Адрес сервиса базы данных |
| `DB_PORT` | Порт PostgreSQL |

В учебной конфигурации используются значения `app/app/app`.
